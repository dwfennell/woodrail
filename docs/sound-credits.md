# Sound credits

The game's recorded sounds (`public/sounds/`) are all from [Freesound](https://freesound.org) under
[CC0](https://creativecommons.org/publicdomain/zero/1.0/): no attribution is required, and they're listed here so each
can be traced. Every page was checked for the CC0 licence on 2026-11-27.

Each was cut to the length the game plays, levelled (one-shots to -1 dBFS peak, loops to about -20 dB mean), made mono,
and saved as AAC (`.m4a`, 64 kbps) or, for the engine loops, 16 kHz WAV so the loop has no gap at its seam. They were
picked by ear in the Sound Lab (`.superpowers/lab/`, not shipped). How the game plays them: `docs/agents/sound.md`.
